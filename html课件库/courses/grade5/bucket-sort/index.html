🪣 认识桶排序

什么是桶排序？

桶排序（Bucket Sort）是一种巧妙的排序算法。它先把数据按范围分到不同的"桶"里，让每个桶里的数据变少，再分别对每个桶排序，最后把桶合并起来。这种 "化大为小、分而治之" 的思想，就是桶排序的核心！

1
📦 分桶
根据数据范围创建若干个桶（数据区间），把数据分配到对应的桶中
2
🔍 桶内排序
对每个桶内的数据分别进行排序（可用选择排序或冒泡排序）
3
🔗 合并
按桶的顺序依次取出数据，组合成完整的有序序列

确定桶的区间

关键点

每个桶代表一个数据区间，数据按照年龄大小"对号入桶"。分桶后，每个桶里的数据量变少了，排序就更简单了！

🔍 第二步：桶内排序

对每个桶分别排序

每个桶里的数据量少了很多，可以用之前学过的选择排序或冒泡排序快速完成排序。

🔗 第三步：合并

按顺序合并所有桶

按照桶的顺序（桶1 → 桶2 → 桶3 → 桶4 → 桶5），依次取出每个桶中已排好序的数据，就得到了完整的从小到大排列的有序序列！

📊 桶排序的优势与不足

优势

✅ 化大为小：把大问题分解为小问题
✅ 效率高：数据分布均匀时，速度非常快
✅ 灵活：可以调整桶的数量优化效率
✅ 直观：思路简单易懂

不足

❌ 占空间：需要额外的桶来存放数据
❌ 依赖分布：数据分布不均匀时效果变差
❌ 需预知范围：需要提前知道数据的大致范围

🎯 本课总结

核心知识点

1. 桶排序是一种"化大为小、分而治之"的排序算法
2. 三个核心步骤：分桶 → 桶内排序 → 合并
3. 桶排序适合数据量大、分布均匀的场景
4. 分治思想不仅用在排序中，也可以用到生活的方方面面
