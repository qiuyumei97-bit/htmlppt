核心驱动问题

如果我们是一栋10层教学楼的"电梯系统设计师"，如何设计一部既安全又高效的电梯控制系统？

项目任务分解

任务一：拆解电梯子系统 —— 电梯由哪些部分组成？

任务二：实现楼层定位 —— 按下按钮，电梯怎么"知道"该去哪？

任务三：设计门控逻辑 —— 电梯门什么时候开、什么时候关？

任务四：构建安全保护 —— 超载了怎么办？有人被夹怎么办？

任务一：找找电梯子系统

门机系统

控制电梯门的打开和关闭，包含电机、门轨和红外传感器。传感器检测是否有人或物体阻挡。

曳引系统

驱动电梯轿厢上下运行的核心动力系统，由曳引机、钢丝绳和对重块组成。

信号控制系统

电梯的"大脑"——接收楼层按钮信号，处理后发出运行指令，控制电梯停靠位置。

安全保护系统

包括超载检测、限速器、紧急制动装置。重量传感器检测超载→触发报警→禁止关门→停止运行。

思考：一个复杂的系统可以分解为多个子系统，每个子系统各司其职、协同工作。
过程与控制：输入 → 计算 → 输出

电梯控制系统可以抽象为「输入 → 计算 → 输出」三个典型环节。

想一想

如果电梯只有"输入→输出"，缺少"计算"环节会怎样？（比如：不管按几楼都直接开门）缺少计算，系统就无法做出正确的判断。

任务二：到达指定的楼层

限位传感器

安装在每层井道中，电梯到达时触发信号，确保精确平层（误差不超过5mm）

楼层选择逻辑

控制器收到按钮信号→判断当前楼层→计算上行/下行→驱动电机到目标楼层

顺序与循环

电梯按顺序处理楼层请求，逐层判断是否停靠，直到所有请求完成

关键概念

按下3楼按钮 = 告诉电梯"请带我到三楼"。电梯控制器需要：①知道当前在哪层 ②计算应该上行还是下行 ③到达目标楼层时触发限位传感器停止。

任务三：电梯门的开与关

门控的核心逻辑：条件判断

规则①：如果红外传感器检测到有人/物阻挡 → 则门立即打开（不关闭）
规则②：如果无人阻挡且门已开超过3秒 → 则门自动关闭
规则③：如果关门过程中检测到有人进入 → 则立即重新开门（防夹保护）

电梯的"感官"——传感器探秘

限位传感器

光电/电磁感应，检测轿厢是否到达指定楼层位置，确保精准平层

重量传感器

安装在轿厢底部，将压力信号转为电信号，超载时触发报警并禁止关门

红外传感器

安装在电梯门上方，发射红外线检测门口是否有物体阻挡

门磁传感器

检测电梯门是否完全关闭，只有确认关门到位才允许电梯运行

传感器 = 电梯的"眼睛"和"耳朵"，它们不断采集数据（检测），控制器根据数据做出判断（计算），再控制电机等执行设备（输出）。这就形成了闭环控制。

任务四：如果超载，电梯停！

超载检测逻辑

重量传感器检测重量 ≥ 额定载重（如1000kg）→ 触发超载信号 → 蜂鸣器报警 → 禁止关门 → 提示乘客减少人数

防夹保护

关门过程中红外传感器持续检测 → 如果有人/物阻挡 → 立即反向开门（不等待3秒）→ 确保人身安全

限速保护

限速器实时监测电梯速度 → 超速时触发安全钳 → 将轿厢紧急制动在导轨上 → 防止坠落

信息社会责任

电梯的安全保护系统不仅是技术实现，更是对生命的尊重。控制系统设计中，「安全优先」是不可动摇的第一原则。理解反馈（feedback）在控制系统中的关键作用——系统通过传感器持续感知状态，一旦发现异常立即做出响应。

知识总结

系统分解

大系统 = 小系统之和
电梯 = 门机+曳引+信号+安全

控制模型

一切过程与控制都可以抽象为
输入 → 计算 → 输出

条件判断

核心逻辑："如果…那么…"
如：如果超载→则报警+禁止关门

反馈机制

传感器持续检测 → 反馈给控制器
→ 调整输出 → 形成闭环控制

核心素养达成

信息意识：认识控制系统在生活中广泛应用（电梯、自动门、红绿灯）

计算思维：能用"输入→计算→输出"模型分析问题，理解条件判断和反馈

信息社会责任：理解"安全优先"原则，认识自主可控技术的重要性
