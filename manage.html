添加课件

💡 新流程：上传后系统会生成 ZIP 包下载，解压到 courses/ 对应年级目录，再运行 generate.bat 即可同步到 Git。

选择 HTML 课件文件，提交后将下载一个 ZIP 包（内含 index.html + meta.json）

📋 手动添加课件的步骤：
1️⃣ 在 courses/年级/ 下新建课件文件夹
2️⃣ 放入 index.html 课件文件
3️⃣ 创建 meta.json（含 title, subject, createdAt）
4️⃣ 双击运行 generate.bat 重新生成索引
5️⃣ git add . && git commit -m "新增课件" && git push
